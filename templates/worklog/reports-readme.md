# Saved Reports

Reports in this folder are generated on demand from the English worklog source (`../daily/` and `../TODOS.md`).

## Naming

```text
YYYY-MM-DD-en.md   # English report
YYYY-MM-DD-ar.md   # Arabic report
```

## When Files Appear Here

Only when you explicitly ask to save, export, or store a report, for example:

- `generate today report and save it`
- `generate today report in Arabic and save it`

Chat-only report generation does not write files here.

## Usage

Copy a saved report into Slack, email, or management updates. The format is structured for readability in Slack (headings and bullet lists).
